# Mira Cognitive OS v1.0 Status

## Capability position

v1.0 is an executable **Level-11-oriented autonomous organization architecture** with **controlled Level-12 improvement mechanics**.

Implemented layers:

1. Cognitive kernel: explicit goals, task graphs, specialist routing, verification and bounded recovery.
2. Persistence: checkpointed runs, event journals and restart/resume.
3. Intelligence abstraction: provider-neutral structured model routing and model-driven planning.
4. Governed tools: risk classes, approval gates, timeouts and audit records.
5. Adaptive cognition: evidence-triggered replanning with bounded replan budgets.
6. Evaluation: baseline/candidate scenario testing and regression detection.
7. Autonomous organization: departments, cross-department dependencies and budgets.
8. Persistent missions: restart-safe organizational execution and event triggers.
9. Promotion governance: human-only promotion approval, invariants, rollback and hash-chained decisions.
10. Executive integration: a single surface that composes missions, adaptation, evidence, tools and improvement control.

## What this does not claim

This repository does not claim AGI or artificial superintelligence. It does not alter model weights by itself, and it does not allow unreviewed self-promotion.

## Remaining production infrastructure

The architecture still needs concrete provider adapters, durable transactional database storage, real sandbox/browser/code workers, external event sources, production observability, concurrency/leases, secrets management, and deployment hardening before it should operate unattended on consequential workloads.

## Governing rule

Agents may discover, propose and evaluate improvements. Production promotion remains governed by regression checks, invariants and explicit human authorization.
